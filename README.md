# Cloud-Based AI Phishing URL Detection Platform

## Overview

This project is an AI-powered phishing URL detection platform developed using Machine Learning, Flask, React, and Cloud Computing technologies.

The system analyzes URL characteristics and predicts whether a website is legitimate or phishing in real time.

---

## Features

* Real-time phishing URL detection
* Machine Learning based prediction
* Flask backend integration
* React frontend interface
* User-friendly web application
* Cloud-based architecture
